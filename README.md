# تصحیح خودکار فارسی برای فایرفاکس

نسخهٔ آزمایشی ۰٫۱ افزونه‌ای برای جایگزینی خودکار متن در کادرهای نوشتن فایرفاکس.

صفحهٔ تنظیمات فارسی و راست‌به‌چپ است و از فونت Vazirmatn استفاده می‌کند؛ اگر فونت روی دستگاه نصب نباشد، نسخهٔ وب آن از مخزن رسمی پروژه از راه jsDelivr دریافت می‌شود.

## بانک واژه‌ها

`dictionary.json` بانک آغازین افزونه است. این فایل از بانک تصحیح خودکار XML فرستاده‌شده تبدیل شده و ۱۱۵۰ جفت واژه دارد. قالب بومی بانک JSON است:

```json
{
  "version": 1,
  "rules": [
    { "trigger": "می روم", "replace": "می‌روم" }
  ]
}
```

پس از نصب، افزونه بانک را در فضای ذخیره‌سازی محلی فایرفاکس قرار می‌دهد. صفحهٔ تنظیمات امکان افزودن، ویرایش، حذف، جست‌وجو و درون‌ریزی/برون‌بری JSON را دارد. هنگام درون‌ریزی، موارد هم‌نام با مقدار تازه جایگزین می‌شوند.

## بارگذاری آزمایشی در فایرفاکس

۱. فایل ZIP را از حالت فشرده خارج کن.
۲. در فایرفاکس به `about:debugging#/runtime/this-firefox` برو.
۳. «Load Temporary Add-on…» را بزن و فایل `manifest.json` داخل پوشهٔ افزونه را انتخاب کن.
۴. برای تنظیم بانک، از صفحهٔ افزونه‌ها یا صفحهٔ `about:addons` وارد تنظیمات «تصحیح خودکار» شو.

بارگذاری موقت تا بستن فایرفاکس معتبر است. برای نصب دائمی و عمومی باید افزونه در فروشگاه افزونه‌های موزیلا ثبت و امضا شود.

## محدودهٔ نسخهٔ آزمایشی

جایگزینی هنگام زدن فاصله، نشانه‌گذاری یا Enter انجام می‌شود. افزونه در صفحه‌های داخلی فایرفاکس و بعضی کادرهای ویرایش پیچیده محدودیت طبیعی دارد. فعلاً فقط فیلدهای متنی فایرفاکس را هدف می‌گیرد و محتوای ورودی را به سرور نمی‌فرستد.
