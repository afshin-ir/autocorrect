# واژه‌بان، تصحیح خودکار فارسی برای فایرفاکس

واژه‌بان هنگام نوشتن در فایرفاکس، واژه‌های ثبت‌شده در بانک را خودکار تصحیح می‌کند و هشت قاعدهٔ جداگانه برای رسم‌الخط و فاصله‌گذاری دارد. مثلاً با روشن‌بودن قاعدهٔ «می/نمی»، پس از زدن فاصله، نشانه‌گذاری یا Enter، «می روم» به «می‌روم» تبدیل می‌شود.

## قابلیت‌ها

- در بانک آغازین، برای ۱۱۷۶ صورتِ غلط یا نامرجّح، صورتِ صحیح یا مرجّح تعیین شده است؛ از جمله صورت‌های املایی و نام‌های خاصِ دارای مرجّح روشن در فهرست ویراست دوم *دستور خطِ فارسی*. افزون بر این بانک، فهرست ۳۰٬۸۶۷ مدخلِ استخراج‌شده از *فرهنگ املایی خط فارسی* برای تصحیح تفاوت‌های فاصله‌گذاری و اعراب معمول به کار می‌رود. مواردی که پس از نادیده‌گرفتن این تفاوت‌ها به بیش از یک مدخل برسند، مبهم شمرده می‌شوند و تغییر نمی‌کنند.
- می‌توانی واژه‌های تازه اضافه کنی، واژه‌های موجود را ویرایش یا حذف کنی و در بانک جست‌وجو کنی.
- مدخل‌های فرهنگ املایی را هم جداگانه جست‌وجو کن، صورت مرجّحشان را ویرایش کن یا تصحیح هر مدخل را خاموش کن. این تغییرها روی دستگاه ذخیره می‌شوند و در پشتیبان JSON هم می‌آیند. مدخل‌های مبهم تا وقتی ابهامشان برطرف نشود خودکار تصحیح نمی‌شوند.
- هنگام نوشتن صورتِ غلط یا نامرجّح، واژه‌های بانک آغازین که با همان حروف شروع می‌شوند همراه با صورتِ تصحیح‌شده‌شان پیشنهاد می‌شوند؛ اگر صورتِ تایپ‌شده دقیقاً در بانک باشد، افزونه آن را مشخص می‌کند.
- می‌توانی بانک واژه‌ها را به‌صورت فایل JSON وارد کنی یا از آن پشتیبان بگیری.
- اگر بخواهی، می‌توانی بانک آغازین را دوباره بازگردانی.
- هشت قاعدهٔ زیر به‌طور پیش‌فرض روشن‌اند و می‌توانی هرکدام را جداگانه در تنظیمات خاموش کنی:
- کارت قواعد جمع‌شونده است؛ شمار قواعد روشن و خاموش را می‌بینی و حالت باز یا بستهٔ آن برای دفعهٔ بعد به خاطر سپرده می‌شود.
  - «می/نمی»: «می روم» ← «می‌روم» و «نمی نویسم» ← «نمی‌نویسم».
  - نشانهٔ جمع «ها» و صورت‌های ضمیری آن: «کتاب ها» و «کتابها» ← «کتاب‌ها»؛ «کتاب هایم» و «کتابهایم» ← «کتاب‌هایم»؛ «کتاب هایش» ← «کتاب‌هایش». این قاعده «های»، «هایت»، «هایمان»، «هایتان» و «هایشان» را هم پوشش می‌دهد.
  - شناسه‌های فعلی «ام/ای/ایم/اید/اند» پس از واژه‌های مختوم به «ه»: «رفته ام» و «رفتهام» ← «رفته‌ام»؛ «رفته ای» ← «رفته‌ای»؛ «نرفته ایم» ← «نرفته‌ایم».
  - پیشوند نفی «بی» در نمونه‌های شناخته‌شدهٔ کتاب: «بی تردید» و «بیتوجه» ← «بی‌تردید» و «بی‌توجه».
  - پسوندهای «تر/ترین»: «بزرگ تر» و «بزرگترین» ← «بزرگ‌تر» و «بزرگ‌ترین»؛ صورت‌هایی مانند «بهتر» و «بیشتر» پیوسته می‌مانند.
  - ترکیب‌های شناخته‌شده با «هم»: «هم بازی» و «همبازی» ← «هم‌بازی».
  - یای نکره، مصدری و نسبت: «خانه ای»، «گره ای»، «کتاب ای» و «دانشجو ای» ← «خانه‌ای»، «گرهی»، «کتابی» و «دانشجویی».
  - تفاوت‌های فاصله‌گذاری و اعرابِ مدخل‌های *فرهنگ املایی خط فارسی*: «آب صاف کن» ← «آب‌صاف‌کُن»؛ «باغ‌بان» و «باغ بان» ← «باغبان»؛ «با شکوه» ← «باشکوه». تطبیق بر پایهٔ همان واژه است و افزونه از روی شباهت املاییِ تقریبی حدس نمی‌زند.
- قاعدهٔ «می/نمی» بر اساس شکل نوشتاری کار می‌کند و فعل‌بودن واژه را تشخیص نمی‌دهد. قواعد «بی» و «هم» به نمونه‌های شناخته‌شده محدودند؛ در بعضی عبارت‌ها، تشخیص معنای واژه از روی شکل نوشتاری ممکن نیست. در قاعدهٔ «ها»، واژه‌های مستقلی مثل «تنها» و «رها» استثنا هستند.
- رابط تنظیمات فارسی و راست‌به‌چپ است.
- بانک واژه‌ها در فضای ذخیره‌سازی محلی فایرفاکس روی دستگاه خودت نگهداری می‌شود. متن‌هایی که می‌نویسی برای تصحیح به سروری فرستاده نمی‌شوند.

افزونه در فیلدهای متنی، کادرهای چندخطی و ویرایشگرهای متنیِ قابل ویرایش سایت‌ها کار می‌کند. صفحه‌های داخلی فایرفاکس و بعضی ویرایشگرهای خاص ممکن است پشتیبانی نشوند. حداقل نسخهٔ موردنیاز فایرفاکس ۱۱۵ است.

## افزودن و مدیریت واژه‌ها

در صفحهٔ تنظیمات، صورت غلط یا نامرجّح را در کادر نخست و صورت صحیح یا مرجّح را در کادر دوم بنویس و «اضافه کن» را بزن. برای تغییر یا حذف هر مورد هم از گزینه‌های همان ردیف استفاده کن.

## مدیریت مدخل‌های فرهنگ املایی

بخش «مدیریت مدخل‌های فرهنگ املایی» را باز کن و بخشی از واژه را جست‌وجو کن. می‌توانی صورت مرجّح را مطابق نیازت تغییر بدهی یا تصحیح آن مدخل را خاموش کنی. برای بازگرداندن صورت فرهنگ، صورت اصلی را دوباره ذخیره کن؛ برای روشن‌کردن مدخل خاموش هم «روشن کن» را بزن. این تغییرها فقط تصحیح مبتنی بر همان مدخل را تغییر می‌دهند و قواعد کلی رسم‌الخط جداگانه فعال می‌مانند.

## قالب فایل JSON

برای واردکردن واژه‌ها، فایل JSON باید فهرستی از قاعده‌ها داشته باشد. در هر قاعده، `trigger` صورت تایپ‌شده و `replace` صورت جایگزین است:

```json
{
  "version": 2,
  "rules": [
    { "trigger": "می روم", "replace": "می‌روم" }
  ],
  "preferredWordOverrides": {
    "آب‌صاف‌کُن": "آب‌صاف‌کن"
  },
  "preferredWordDisabled": [
    "باغبان"
  ]
}
```

اگر قاعده‌ای با همان `trigger` از قبل در بانک باشد، مقدار واردشده جای آن را می‌گیرد. فایل‌های نسخهٔ ۱ که فقط `rules` دارند همچنان پشتیبانی می‌شوند. هنگام پشتیبان‌گیری، افزونه واژه‌های سفارشی و تغییرهای مدخل‌های فرهنگ را هم در JSON قرار می‌دهد.
