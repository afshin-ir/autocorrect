# تصحیح خودکار فارسی برای فایرفاکس

این افزونه واژه‌هایی را که در بانک آن تعریف کرده‌ای، هنگام نوشتن در فایرفاکس خودکار تصحیح می‌کند. برای نمونه، اگر قاعدهٔ «می روم ← می‌روم» در بانک باشد، با زدن فاصله، نشانه‌گذاری یا Enter، «می روم» به «می‌روم» تبدیل می‌شود.

## قابلیت‌ها

- بانک آغازین شامل حدود ۱۱۵۰ جفت واژه است.
- می‌توانی واژه‌های تازه اضافه کنی، واژه‌های موجود را ویرایش یا حذف کنی و در بانک جست‌وجو کنی.
- می‌توانی بانک واژه‌ها را به‌صورت فایل JSON وارد کنی یا از آن پشتیبان بگیری.
- اگر بخواهی، می‌توانی بانک آغازین را دوباره بازگردانی.
- رابط تنظیمات فارسی و راست‌به‌چپ است.
- بانک واژه‌ها در فضای ذخیره‌سازی محلی فایرفاکس روی دستگاه خودت نگهداری می‌شود. متن‌هایی که می‌نویسی برای تصحیح به سروری فرستاده نمی‌شوند.

افزونه در فیلدهای متنی، کادرهای چندخطی و ویرایشگرهای متنیِ قابل ویرایش سایت‌ها کار می‌کند. صفحه‌های داخلی فایرفاکس و بعضی ویرایشگرهای خاص ممکن است پشتیبانی نشوند. حداقل نسخهٔ موردنیاز فایرفاکس ۱۱۵ است.

## افزودن و مدیریت واژه‌ها

در صفحهٔ تنظیمات، صورت نادرست یا نامرجح را در کادر نخست و صورت درست یا مرجح را در کادر دوم بنویس و واژه را اضافه کن. برای تغییر یا حذف هر مورد هم از گزینه‌های همان ردیف استفاده کن.

## قالب فایل JSON

برای واردکردن واژه‌ها، فایل JSON باید فهرستی از قاعده‌ها داشته باشد. در هر قاعده، `trigger` صورت تایپ‌شده و `replace` صورت جایگزین است:

```json
{
  "version": 1,
  "rules": [
    { "trigger": "می روم", "replace": "می‌روم" }
  ]
}
```

اگر قاعده‌ای با همان `trigger` از قبل در بانک باشد، مقدار واردشده جای آن را می‌گیرد. هنگام پشتیبان‌گیری، افزونه فایل JSON بانک فعلی را دریافت می‌کند.

## بارگذاری آزمایشی از روی کد

۱. مخزن را دریافت و فایل ZIP آن را از حالت فشرده خارج کن.
۲. در فایرفاکس به `about:debugging#/runtime/this-firefox` برو.
۳. گزینهٔ **Load Temporary Add-on…** را بزن و فایل `manifest.json` را از پوشهٔ افزونه انتخاب کن.
۴. برای بازکردن تنظیمات، روی دکمهٔ افزونه در نوار ابزار فایرفاکس بزن.

افزونه‌ای که به این روش بارگذاری می‌شود موقت است و با بستن فایرفاکس از این حالت خارج می‌شود.
